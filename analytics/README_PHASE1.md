# Phase 1 — Project Setup

This delivers the **application-specific** code for Phase 1 — not the Laravel
framework skeleton itself (that's generated by Composer, not hand-written).

## 1. Create the base Laravel 12 project

```bash
composer create-project laravel/laravel website-audit-platform "12.*"
cd website-audit-platform
```

## 2. Copy in these files

Copy every file in this bundle into the matching path in your new project
(they mirror Laravel's own folder layout 1:1):

```
app/Audit/...                      -> app/Audit/...
app/Http/Controllers/AuditController.php
app/Http/Requests/StoreAuditRequest.php
app/Models/Audit.php               -> overwrite the default
app/Providers/AuditServiceProvider.php
app/Support/helpers.php
config/audit.php
database/migrations/2026_08_06_000000_create_audits_table.php
public/css/app.css
public/js/app.js
resources/views/...                -> overwrite the default welcome view
routes/web.php                     -> overwrite the default
```

## 3. Register the service provider

Laravel 12 uses `bootstrap/providers.php` (not `config/app.php`). Add:

```php
return [
    App\Providers\AppServiceProvider::class,
    App\Providers\AuditServiceProvider::class,
];
```

## 4. Autoload the helper file

In `composer.json`:

```json
"autoload": {
    "files": [
        "app/Support/helpers.php"
    ],
    "psr-4": {
        "App\\": "app/"
    }
}
```

Then run:

```bash
composer dump-autoload
```

## 5. Environment

Append the contents of `.env.additions` to your `.env` and `.env.example`,
then set your real MySQL credentials.

## 6. Migrate

```bash
php artisan migrate
```

## 7. Serve

```bash
php artisan serve
```

Visit `/` — submit a URL and you'll be redirected to `/audits/{uuid}`
showing a "Queued" status page.

---

## What's deliberately NOT in this phase

- No crawler, no analyzers, no scoring, no queue job, no exports.
- `AuditService::submit()` only creates the `audits` row with status
  `queued` — the pipeline that moves it through `fetching → crawling →
  analyzing → generating_report → completed` is wired up starting in the
  **Crawler Engine** phase, per the phase plan.
- `config/audit.php` and the `.env` crawler keys are defined now (so the
  config surface is stable) but nothing reads them yet.
